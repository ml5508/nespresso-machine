Four-state model

  1. Off: the button light is off.
  2. Ready: the machine is on and waiting. It checks for water, a new capsule, and a closed lid when you press the main button.
  3. Brewing: the button pulses while a timer fills the progress bar.
  4. Finished: coffee is ready; eject the used capsule to return to Ready.
