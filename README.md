# Nespresso Vertuo Pop Coffee Machine Simulator

## Project Overview

This project is a simple interactive simulation of my Nespresso Vertuo Pop capsule coffee machine, built using HTML, CSS, and JavaScript.

The goal is to explore how user actions and conditions affect the machine's states and behavior.

## Main Features

- Four main states: Off, Ready, Brewing, and Finished
- One main coffee button that performs different actions depending on the current state
- Controls for adding water, inserting a capsule, and locking the lid
- Warning messages when brewing conditions are not met
- Visual feedback showing the current machine state and brewing progress

## Technologies Used

- **HTML:** Creates the structure of the webpage
- **CSS:** Controls the layout and visual design
- **JavaScript:** Handles user interactions, conditions, and state transitions

## How to Use

1. Open the webpage.
2. Turn on the coffee machine.
3. Add water and insert a coffee capsule.
4. Close and lock the lid.
5. Press the main coffee button to start brewing.
6. Watch the brewing progress and the machine's state changes.

## Learning Goals

Through this project, I explored how to:

- Represent real-world appliance behavior using variables and states
- Use conditional statements (`if/else`) to control interactions
- Use event listeners to respond to user actions
- Test and revise an interactive model with AI assistance
